# Onur Karataş

Machine technician student and software developer from İzmir, Türkiye. Developer of **[AXON Precision](https://axonprecision.org)**, a calculation suite for machine operators and quality control (desktop and iOS). Bridging **Mechanical Design (CAD/CAM)**, **Industrial Automation**, and **Software Engineering**.

Studying Machinery at İzmir Konak Vocational School and Computer Programming at Atatürk University (Open Education). Completed **Harvard CS50x**.

---

- ⚙️ **Mechanical Systems & CAD:** SolidWorks, AutoCAD, CNC Programming (G/M-Code), Kinematic Prototyping
- 📐 **Quality & Metrology:** ISO 286 tolerances and fits, SPC (Cp/Cpk), measurement tools
- 💨 **Fluid Power & Automation:** Pneumatic circuits, electro-pneumatic systems, process automation (PBOS)
- 💻 **Software Development:** AXON Precision (TypeScript, React, Rust/Tauri), Harvard CS50x (C, Python, SQL)
